Project Overview

A production-ready AI assistant that processes multiple document sources (PDFs, YouTube transcripts, and text snippets) to answer complex queries while automatically detecting and resolving conflicts between facts. The system ensures deterministic, auditable, and explainable decisions.

✓ Completed Components

1. Multi-Source Ingestion Pipeline

✓Handles PDFs, YouTube transcripts, and text snippets

  • PyPDFLoader for PDF processing
  • YouTube Transcript API for video transcripts
  • RecursiveCharacterTextSplitter for chunking
  • Sentence-transformers embeddings (all-MiniLM-L6-v2)
  • Temporal metadata tracking

2. Conflict Detection Engine

✓Identifies contradictions between facts from multiple sources

  • Direct contradiction detection ("A is X" vs "A is Y")
  • Temporal conflict detection (state changes over time)
  • Internal inconsistency detection (contradictions within sources)
  • Temporal marker extraction (years, months, dates)
  • Configurable severity levels (high, medium, low)

3. Deterministic Conflict Resolution Engine

✓Applies rule-based logic to resolve conflicts

  • Source reliability hierarchy: PDF (1.0) > YouTube (0.7) > Text (0.5)
  • Temporal recency preference
  • Internal consistency checking
  • Confidence scoring
  • Insufficient evidence handling

4. Auditable Decision Trace System

✓Generates complete JSON audit trails for all decisions

  • Comprehensive trace generation
  • JSON audit trail export
  • Deterministic hash verification
  • Replay verification for testing
  • Decision explanation and justification

5. Streamlit Web UI

✓Interactive interface for document ingestion and querying

  • PDF file upload
  • YouTube URL input
  • Text snippet entry
  • Query processing with real-time feedback
  • Conflict visualization
  • Audit trail export
  • Query history tracking

Quick Start

Installation (5 minutes)

git clone https://github.com/yourusername/temporal-conflict-rag.git
cd temporal-conflict-rag

# Create virtual environment
python -m venv venv
source venv/bin/activate  # or: venv\Scripts\activate on Windows

# Install dependencies
pip install -r requirements.txt

Run Application

streamlit run app.py

The app will open at http://localhost:8501

Run Tests

pytest test_rag_system.py -v --cov=.
